# PDF Markup

Mark up and measure PDF drawings on a tablet or phone: clouds, text, callouts, stamps, length, area and count, with a markups list and Excel export.

Open https://curiouskid05.github.io/pdf-markup/ once, then add it to the home screen (iPad: Share → Add to Home Screen). After that it works offline. PDFs and markups stay on the device; nothing is uploaded.

Built from the PC tool by `build-phone-app.ps1 pdf`. Don't edit these files by hand.
